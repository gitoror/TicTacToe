# nought.

A polished tic-tac-toe game with an unbeatable training AI, move coaching,
same-screen multiplayer, and private online rooms.

```powershell
npm install
npm run dev
```

Open `http://localhost:5173`. Use `npm run dev:network` to make the development
server reachable from another device on the same local network.

See [PLAYING.md](PLAYING.md) for game modes, checks, GitHub Pages deployment,
and the server requirements for online rooms.
